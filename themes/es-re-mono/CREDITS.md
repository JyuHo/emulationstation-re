# es-re-mono theme credits

## Console and platform logos

The SVG logos in `art/logos/` come from **Monochrome (Retro) Gaming Logos** by
[HVR88](https://github.com/HVR88/Monochrome-Gaming-Logos).

They are used with attribution, as requested by the collection's author. The
collection mixes original designs with recreations of third-party marks; those
marks remain the property of their owners. Some logos may not be suitable for
commercial use. See the collection's README for the full usage disclaimer:

- https://github.com/HVR88/Monochrome-Gaming-Logos

If a system has no logo here, EmulationStation falls back to its name.

## Fonts

- **Ubuntu Condensed** for headings, from the resources already shipped with
  EmulationStation-RE.
- **Rubik** for body text, from the resources already shipped with
  EmulationStation-RE.

## Help icons

The help bar uses the button glyphs already shipped in `resources/help/`
(A/B/X/Y, L/R, Start/Select, D-pad and F1). No third-party icon set is added.

## Theme

The layout, backgrounds and UI graphics in this directory are part of
EmulationStation-RE and follow the project's MIT license.
